# Портфолио-сайт — инструкция

Статическая страница, без сборки и зависимостей. Открывается двойным кликом по `index.html`.

```
portfolio-site/
├── index.html            ← весь текст страницы
├── README.md             ← этот файл
├── Ilya-Voitov-CV.pdf    ← резюме, которое скачивают с сайта
└── assets/
    ├── style.css         ← оформление
    └── media/            ← фото проектов, шоурил и его постер
```

Вторая, чёрная вёрстка (`atelier.html` + `atelier.css`) удалена 1 августа 2026 —
осталась одна страница.

Все кадры 4:3 — под сетку `.exhibit__media` (на мобильном она становится 16:10, поэтому
сюжет держим по центру). Все файлы до 400 КБ. **Лиц в кадре нет** — сознательное
ограничение: на двух снимках люди есть, но строго со спины или только руки.

**Как заменить фото.** Положить новый файл в `assets/media/` под тем же именем — вёрстку
трогать не надо. Если имя другое, поправить `src` в `index.html` и обязательно переписать
`alt` — его читают поисковики и скринридеры.

**Требования к фото:** горизонтальные 4:3, от 1200 px по ширине, до 400 КБ после сжатия.
Лучше всего работают снимки, где посетители взаимодействуют с экспонатом.
Скажи — пережму любое фото одной командой.

## 2. Showreel

Вставлен как локальный файл, без Vimeo и YouTube:

```
assets/media/showreel.mp4          42 МБ · 1920×1080 · 2 мин 20 с · H.264 + AAC
assets/media/showreel-poster.jpg   кадр-обложка, показывается до нажатия play
```

Исходник (`IVShowreelF.mp4`, 346 МБ) пережат через ffmpeg: `-crf 22 -preset slow` с
потолком битрейта `-maxrate 3000k`, плюс `-movflags +faststart`, чтобы ролик начинал
играть до полной загрузки. Видео стоит с `preload="none"` — до нажатия play грузится
только постер.

**Как обновить ролик:**

```bash
ffmpeg -i НОВЫЙ.mp4 -c:v libx264 -preset slow -crf 22 -maxrate 3000k -bufsize 6000k \
       -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart assets/media/showreel.mp4
ffmpeg -ss 4 -i assets/media/showreel.mp4 -frames:v 1 -qscale:v 4 \
       assets/media/showreel-poster.jpg
```

Постер снимается с 4-й секунды — там карточка `PROJECT / Planet Ocean` на общем плане
корпуса. Не берите кадр из середины: на многих планах в нижней трети висит титр, и на
обложке он выглядит как случайно вставший на паузу ролик.

Если размер ролика перевалит за 100 МБ, GitHub его не примет — тогда либо сильнее жать
(`-crf 26`), либо заливать на Vimeo и возвращать `<iframe>` внутрь `<div class="reel__frame">`.

## 3. Опубликовать на GitHub Pages

1. Создать на GitHub пустой репозиторий с именем **`skaijidev.github.io`** — именно так,
   тогда сайт откроется по адресу `https://skaijidev.github.io` без подпапок.
   Без README, без .gitignore — совсем пустой.
2. Сказать мне — я закоммичу и запушу содержимое этой папки. При push нужно будет ввести
   логин GitHub и токен доступа (не пароль — GitHub принимает Personal Access Token,
   создаётся в Settings → Developer settings → Personal access tokens).
3. В репозитории: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт открывается. Первая публикация иногда занимает до 10 минут.
